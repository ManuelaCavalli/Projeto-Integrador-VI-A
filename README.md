# Projeto Integrador VI-A - Brick Breaker

Este repositório contém a implementação do jogo **Brick Breaker** desenvolvido para a disciplina de Projeto Integrador. O objetivo do jogo é destruir blocos rebatendo uma bola com uma plataforma controlada pelo usuário.

## 🚀 Como Executar o Projeto
1. Clone este repositório.
2. Abra a pasta raiz no **Android Studio**.
3. Aguarde o sincronismo do Gradle.
4. Execute em um emulador ou dispositivo físico (Android 7.0+).
