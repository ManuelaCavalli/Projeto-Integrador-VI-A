# Apresentação do Wireframe

Este documento apresenta os protótipos de interface desenvolvidos para o aplicativo **Brick Breaker**.

## 🎨 Design das Telas
O design foi focado na usabilidade e na clareza visual, garantindo que o usuário possa focar no gameplay sem distrações.

### 1. Tela Inicial (Menu)
- Três botões centrais: "Integrantes", "Iniciar Jogo" e "Configurações".
- Design limpo com fundo contrastante.

### 2. Tela de Integrantes
- Lista organizada dos membros do grupo com fácil navegação de retorno.

### 3. Tela de Configurações
- Seleção intuitiva de padrões de cores e tamanhos de blocos via menus de seleção (Spinners).

### 4. Tela de Jogo (Níveis)
- Layout que ocupa o máximo da tela do dispositivo.
- Indicador de nível e pontuação no topo.
- Representação visual dos 5 padrões de blocos (Nível 1 a 5).
